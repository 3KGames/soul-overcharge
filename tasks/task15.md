# Task 15 — Жёсткий потолок `MaxOmega`

## Проблема

`EngineService.MaxOmega` объявлен как «Потолок оборотов, рад/с. Потолок крутящего
момента», но используется ТОЛЬКО для смягчения кривой момента:

```csharp
float rpmNorm = Mathf.Clamp01(omega * (30f / Mathf.PI) / MaxRPM);
```

Само `angularSpeed` ничем не ограничено. Наблюдаемые 10 125 об/мин при пределе
7 500 — мотор физически не может столько крутить, поршень по скорости не успевает,
но модель это разрешает.

Вторая половина проблемы: выше потолка момент не падает. При `rpmNorm = 1` лестница
Лейдермана даёт `A + B - C = 1 + 1 - 1 = 1`, то есть момент остаётся
`80.48 Н*м` на ЛЮБЫХ оборотах выше предела. У настоящего двигателя он сходит в ноль.

Пользователь отдельно указал: отдельный ограничитель оборотов не нужен, должно
работать само по существующему `MaxOmega`. Это и делаем — отдельного «лимитера»
не создаём.

## Что сделать

В `EngineService.UpdateAngularSpeed` добавить жёсткий потолок симметрично
существующему аварийному полу:

```csharp
public void UpdateAngularSpeed(float dt, float effectiveTorque)
{
    angularSpeed += (effectiveTorque / Inertia) * dt;

    // Аварийный пол ... (существующий комментарий не трогать)
    angularSpeed = Mathf.Max(StallOmega, angularSpeed);

    // Потолок по скорости поршня. Без него мотор уходит за предел, а момент
    // выше предела не падает, потому что кривая упёрта в Clamp01.
    angularSpeed = Mathf.Min(MaxOmega, angularSpeed);
}
```

Требования к реализации:

1. Потолок ставить ПОСЛЕ интегрирования, рядом с полом, одним местом.
2. Существующий комментарий про аварийный пол и саму строку `Mathf.Max(StallOmega, ...)`
   не менять.
3. Закомментированные строки в файле не трогать.
4. Ничего кроме этой строки в `EngineService` не менять: `CalculateTorque`,
   `CalculateTorqueAt`, `CalculateFriction`, конструктор, `PeakTorque` — не трогать.
5. `TransmissionService`, `DrivetrainService`, стейты, петлю физики — не трогать.

## Критерии приёмки

- `EngineService.UpdateAngularSpeed` содержит `Mathf.Min(MaxOmega, angularSpeed)`.
- `MaxOmega = 1000 * П * 0.02 / 0.08 = 785.398 рад/с`, `MaxRPM = 7500 об/мин`.
- Аварийный пол на `StallOmega` продолжает работать: из любого состояния обороты
  могут упасть ниже `IdleOmega` до `StallOmega` и там остаться.
- Потолок достижим и не перекрывает пол: `StallOmega = 500 об/мин` < `MaxRPM = 7500`.
- `dotnet build Assembly-CSharp.csproj` — 0 ошибок, новых предупреждений нет.
- `dotnet build Assembly-CSharp-Editor.csproj` — 0 ошибок, новых предупреждений нет.
